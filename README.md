# 📈 Zerodha Clone

A full-stack trading platform inspired by Zerodha, built to practice and demonstrate modern web development concepts.

## 🚀 Features

- 🔐 User Signup & Login
- 👤 User Authentication
- 📊 Trading Dashboard
- 📈 Watchlist Management
- 💼 Portfolio & Holdings
- 📋 Orders Management
- 📱 Responsive User Interface
- 🔄 Frontend & Backend API Integration

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- CSS

### Dashboard
- React.js
- Material UI

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
